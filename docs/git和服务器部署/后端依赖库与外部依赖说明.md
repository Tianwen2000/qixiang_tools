# 后端依赖库与外部依赖说明

本文说明项目后端运行、文档转换、浏览器渲染和生产部署所需的依赖。Python 包以项目依赖清单为准；需要在操作系统中单独安装的程序在本文详细说明。

## 1. 后端 Python 依赖库

完整依赖及版本范围统一维护在：

- [backend/requirements.txt](../../backend/requirements.txt)

不要在部署文档中重复维护另一份包名列表，避免两处版本不一致。

本地 Windows 安装：

```powershell
cd D:\tianwen_project\GitHub_project\qixiang_tools\backend
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Ubuntu 服务器安装：

```bash
cd /home/ubuntu/qixiang_tools
./backend/.server-venv/bin/python -m pip install -r backend/requirements.txt
./backend/.server-venv/bin/python -m pip check
```

> SQLite 由 Python 标准库 `sqlite3` 提供，本地使用 SQLite 时不需要额外安装 Python 包或数据库服务。

## 2. 外部依赖总览

| 外部依赖 | 是否必须 | 用途 |
|---|---|---|
| Python 3.12 + venv | 后端必须 | 运行 FastAPI、安装 `requirements.txt` |
| MySQL | 生产环境必须 | 登录会话、工具使用日志等持久化数据 |
| nginx | 当前生产架构必须 | 托管 `frontend/dist`，并将 `/api` 反向代理到后端 |
| LibreOffice | 对应功能必须 | 高保真 Word 转 PDF、PPT 转 PDF |
| Playwright Chromium | 对应功能必须 | 动画 SVG 的浏览器渲染、拆帧及 GIF 转换 |
| FFmpeg | 通常无需单独安装，建议服务器安装 | 音视频转换、GIF/APNG/WebP/AVIF 动图处理 |
| Node.js + npm | 前端构建必须 | 安装前端依赖并生成 `frontend/dist`；仅托管现成 `dist` 时服务器可不安装 |
| 中文字体 | 推荐 | 避免 LibreOffice 和 Chromium 渲染中文时字体替换、缺字或版式漂移 |
| systemd | 当前 Ubuntu 部署使用 | 托管和重启 `qixiang-backend` 服务 |

## 3. MySQL

生产环境通过 `DATABASE_URL` 连接 MySQL，配置模板见：

- [backend/.env.example](../../backend/.env.example)

示例格式：

```dotenv
DATABASE_URL=mysql+pymysql://用户名:密码@127.0.0.1:3306/qixiang_tools?charset=utf8mb4
```

Ubuntu 常用安装与检查命令：

```bash
sudo apt update
sudo apt install -y mysql-server
sudo systemctl enable --now mysql
sudo systemctl status mysql --no-pager
mysqladmin ping
```

本地开发可以改用 SQLite：

```dotenv
DATABASE_URL=sqlite:///./local_ai.db
```

SQLite 适合本地体验；生产环境仍建议使用 MySQL。数据库连接失败通常表现为 `Can't connect to MySQL server`，此时检查 MySQL 服务、端口、账号权限和 `DATABASE_URL`。

## 4. LibreOffice

LibreOffice 不是 Python 包，必须单独安装。以下功能依赖它：

- Word 转 PDF
- PPT 转 PDF

对应实现：

- [backend/app/tools/docx_to_pdf.py](../../backend/app/tools/docx_to_pdf.py)
- [backend/app/tools/ppt_to_pdf.py](../../backend/app/tools/ppt_to_pdf.py)

Windows 默认安装位置会被代码自动识别：

```text
C:\Program Files\LibreOffice\program\soffice.exe
```

Ubuntu 安装与验证：

```bash
sudo apt update
sudo apt install -y libreoffice
libreoffice --headless --version
```

代码会依次查找 `LIBREOFFICE_PATH`、系统 `PATH` 中的 `soffice`/`libreoffice` 和 Windows/macOS 常见安装位置。正常加入 `PATH` 后不必配置；无法自动找到时可在后端环境中增加：

```dotenv
LIBREOFFICE_PATH=/usr/bin/libreoffice
```

修改环境变量后需要重启后端服务：

```bash
sudo systemctl restart qixiang-backend
```

## 5. Playwright Chromium

`requirements.txt` 中的 `playwright` 只是 Python 控制库，Chromium 浏览器内核和 Linux 系统组件需要另外安装。以下功能依赖浏览器：

- 动画 SVG 拆帧
- 动画 SVG 转 GIF

对应实现：

- [backend/app/tools/svg_image_converter.py](../../backend/app/tools/svg_image_converter.py)
- [backend/app/tools/svg_animation_converter.py](../../backend/app/tools/svg_animation_converter.py)

Windows 本地安装：

```powershell
cd D:\tianwen_project\GitHub_project\qixiang_tools\backend
.\.venv\Scripts\python.exe -m playwright install chromium
```

Ubuntu 服务器建议把浏览器固定安装到项目目录，避免 systemd 服务用户找不到其他用户缓存中的浏览器：

```bash
cd /home/ubuntu/qixiang_tools
export PLAYWRIGHT_BROWSERS_PATH=/home/ubuntu/qixiang_tools/.playwright-browsers
./backend/.server-venv/bin/python -m playwright install --with-deps chromium
```

并在后端 `.env` 或 systemd 服务环境中保留同一路径：

```dotenv
PLAYWRIGHT_BROWSERS_PATH=/home/ubuntu/qixiang_tools/.playwright-browsers
```

安装命令和后端服务必须使用同一 Linux 用户，目录也必须允许该用户读取和执行。出现 `Executable doesn't exist` 或“未找到 Playwright Chromium 浏览器内核”时，重点检查安装用户、`PLAYWRIGHT_BROWSERS_PATH` 和目录权限。

## 6. FFmpeg

FFmpeg 用于音视频互转和部分动图处理，对应实现主要位于：

- [backend/app/tools/media_converter.py](../../backend/app/tools/media_converter.py)
- [backend/app/tools/animated_frames_converter.py](../../backend/app/tools/animated_frames_converter.py)

项目会优先使用系统 `PATH` 中的 `ffmpeg`；找不到时，会回退到 `requirements.txt` 中 `imageio-ffmpeg` 提供的可执行文件。因此完整安装 Python 依赖后，通常不必再单独安装 FFmpeg。

生产服务器仍建议安装系统 FFmpeg，便于排错并获得更完整的编解码支持：

```bash
sudo apt update
sudo apt install -y ffmpeg
ffmpeg -version
```

若只有 AVIF 等个别格式失败，应进一步检查当前 FFmpeg 构建是否包含目标编码器，而不是重复安装 Python 包。

## 7. Node.js、npm 与 nginx

Node.js 和 npm 只负责前端开发与构建，依赖定义见：

- [frontend/package.json](../../frontend/package.json)

建议使用当前 Node.js LTS 版本：

```bash
cd frontend
npm install
npm run build
```

构建结果位于 `frontend/dist`。当前生产环境由 nginx 直接托管该目录，并把 `/api` 转发到 `127.0.0.1:8000`。

- 如果服务器只接收已经构建好的 `frontend/dist`，服务器不必安装 Node.js。
- 如果服务器或 CI 需要执行 `npm run build`，则必须安装 Node.js 和 npm。

nginx 检查命令：

```bash
sudo nginx -t
sudo systemctl status nginx --no-pager
```

## 8. 中文字体

中文字体不是接口启动的硬依赖，但会直接影响 LibreOffice 文档导出和 Chromium 截图的视觉效果。Ubuntu 建议安装 Noto CJK 字体：

```bash
sudo apt update
sudo apt install -y fonts-noto-cjk fontconfig
sudo fc-cache -fv
```

源文件使用了服务器不存在的商业字体时，LibreOffice 仍会进行字体替换，转换结果可能与原文件略有差异。要获得更高保真度，需要在遵守字体授权的前提下安装源文件所用字体。

## 9. 部署后检查

```bash
cd /home/ubuntu/qixiang_tools

# Python 环境与包依赖
./backend/.server-venv/bin/python --version
./backend/.server-venv/bin/python -m pip check

# 外部程序
libreoffice --headless --version
ffmpeg -version
mysqladmin ping
sudo nginx -t

# 服务与接口
sudo systemctl restart qixiang-backend
sudo systemctl status qixiang-backend --no-pager
curl -s http://127.0.0.1:8000/api/health
```

## 10. 依赖变更规则

- 新增或升级 Python 包：修改 `backend/requirements.txt`，服务器重新执行 `pip install -r` 后重启后端。
- 新增外部程序：同时更新本文，写清用途、安装命令、检测方式和缺失时的报错。
- 修改 `.env` 或 systemd 环境变量：重启 `qixiang-backend` 后才会生效。
- 前端依赖变化：重新安装 npm 依赖并执行 `npm run build`，确保同步最新 `frontend/dist`。
