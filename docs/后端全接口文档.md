# 后端全接口文档

> 本文按当前 FastAPI 路由整理，基础前缀为 `/api`。接口真实在线调试页可访问 `/docs`，例如本地开发环境为 `http://127.0.0.1:8000/docs`。

## 通用响应

成功响应通常为：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

失败响应通常为：

```json
{
  "code": 4001,
  "message": "错误说明",
  "data": null
}
```

文件类工具成功时会直接返回文件流，不走普通 JSON 响应。

## 工具元信息

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/categories` | 获取全部工具大类 |
| `GET` | `/api/tools` | 获取工具列表 |
| `GET` | `/api/tools/{slug}` | 获取单个工具详情 |

`GET /api/tools` 查询参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `category` | 否 | 按分类筛选，如 `ops`、`format`、`game` |
| `keyword` | 否 | 按关键词搜索工具 |

说明：

- 工具元信息来自 `backend/app/configs/categories.json` 和 `backend/app/configs/tools.json`。
- 前端导航、工具卡片、工具详情页大多依赖这些接口自动渲染。

## 工具执行接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/tools/{slug}/execute` | 执行文本、表单类工具 |
| `POST` | `/api/tools/{slug}/upload` | 执行文件上传类工具 |

### 文本/表单工具执行

`POST /api/tools/{slug}/execute`

请求体：

```json
{
  "text": "输入文本",
  "params": {
    "action": "format"
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `text` | 否 | 文本输入内容 |
| `params` | 否 | 工具参数对象，不同工具参数不同 |

返回说明：

- 文本结果返回 JSON。
- 文件结果返回文件流。
- `local-ip-lookup` 会额外读取请求来源 IP 作为本站服务端视角 IP。

### 文件上传工具执行

`POST /api/tools/{slug}/upload`

请求类型：`multipart/form-data`

| 字段 | 必填 | 说明 |
|---|---|---|
| `file` | 是 | 上传文件 |
| `params` | 否 | JSON 字符串，如 `{"direction":"mp3_to_wav"}` |

说明：

- 上传文件会进入后端临时目录。
- 文件处理成功后，如果结果是文件，会返回下载文件流。
- 请求完成后会清理本次请求的临时输入和输出目录。
- 上传类型和大小由 `backend/app/utils/validators.py` 与 `.env.local` 配置共同控制。

## AI 登录体系

这套登录用于工具站 AI 助手，不等同于独立后台账号。

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/auth/register` | 注册账号，成功后自动登录 |
| `POST` | `/api/auth/login` | 登录账号 |
| `GET` | `/api/auth/me` | 获取当前登录用户 |
| `POST` | `/api/auth/logout` | 退出登录 |

注册/登录请求体：

```json
{
  "account": "15573808035",
  "password": "deng1201"
}
```

说明：

- 登录成功后后端写入 HttpOnly Cookie。
- Cookie 名称由 `SESSION_COOKIE_NAME` 控制，默认 `qx_session`。
- 登录有效期由 `SESSION_EXPIRE_DAYS` 控制。
- `POST /api/auth/logout` 会清除 Cookie 和服务端 session。
- 注册、登录、退出会记录账号活动日志。

## AI 对话接口

当前 AI 对话仍是占位实现，真实模型尚未接入。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/chat/models` | 获取模型选择列表 |
| `POST` | `/api/chat` | AI 对话接口 |

`POST /api/chat` 请求体：

```json
{
  "message": "你好",
  "model": "tianwen-1",
  "history": [
    {
      "role": "user",
      "content": "你好"
    },
    {
      "role": "assistant",
      "content": "你好呀"
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `message` | 是 | 当前用户输入 |
| `model` | 否 | 模型 ID，未传时使用默认模型 |
| `history` | 否 | 历史消息，最多 20 条 |

说明：

- 需要 AI 登录 Cookie。
- `history.role` 只支持 `user` 和 `assistant`。
- 当前返回示例回复，后续接真实模型时主要改 `backend/app/api/routes/chat.py`。

## 反馈系统

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/feedback` | 提交用户反馈 |

请求体：

```json
{
  "content": "反馈内容",
  "feedbackType": "bug",
  "toolSlug": "free-translate",
  "toolName": "免费翻译",
  "toolUrl": "http://127.0.0.1:5173/feedback?tool=free-translate",
  "contactType": "email",
  "contactValue": "test@qq.com",
  "submittedPage": "http://127.0.0.1:5173/feedback",
  "userAgent": "Mozilla/5.0 ..."
}
```

说明：

- 提交反馈不要求登录。
- 如果请求携带有效 AI 登录 Cookie，后端会记录提交者账号。
- 未登录时账号为空。
- 字段会在服务层按数据库列长度做截断保护。

## 工具使用日志

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/tool-usage-logs` | 静默记录一条工具使用行为摘要 |

请求体示例：

```json
{
  "toolId": "json-format",
  "toolName": "JSON 格式化",
  "category": "dev",
  "action": "convert",
  "success": true,
  "durationMs": 36,
  "inputLength": 120,
  "outputLength": 168,
  "errorCode": "",
  "errorMessage": "",
  "sourcePage": "http://127.0.0.1:5173/tool/json-format",
  "deviceId": "web-xxxx"
}
```

说明：

- 不要求登录；携带有效 AI 登录 Cookie 时，后端会附带记录账号。
- 后端从请求中提取 IPv4 和 User-Agent。
- 只记录工具、动作、成功状态、耗时、长度和截断后的错误摘要，不保存用户的完整输入或输出。
- 常见 `action` 为 `view`、`click`、`convert`、`copy`、`clear`。
- 写入依赖数据库；失败时返回错误，但前端上报采用静默处理，不影响工具本身使用。

## 独立后台入口

这套接口用于“琦湘工具站后台管理”，不复用 AI 用户登录态。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/backoffice/challenge` | 获取后台入口问题 |
| `POST` | `/api/backoffice/entry` | 提交入口答案，获取后台入口路径 |
| `POST` | `/api/backoffice/entry/consume` | 消费一次性后台入口 ticket |

`POST /api/backoffice/entry` 请求体：

```json
{
  "answer": "我的爱"
}
```

返回数据示例：

```json
{
  "path": "/qx-backoffice/一次性ticket"
}
```

`POST /api/backoffice/entry/consume` 请求体：

```json
{
  "ticket": "一次性ticket"
}
```

说明：

- 后台入口问题和答案只从服务端环境变量读取。
- ticket 短时有效，且只能消费一次。
- 入口验证只负责进入后台登录页，不等同于后台登录。
- 接口仍完整支持 `/qx-backoffice/{ticket}` 路径和 ticket 消费；但当前 `SiteHeader.vue` 在答案通过后实际写入一个两分钟的 `localStorage` gate，并打开不带 ticket 的 `/qx-backoffice`，没有消费返回的 ticket。直接访问带 ticket 的路径时，`BackofficePage.vue` 才会调用消费接口。
- `localStorage` gate 和 ticket 都只控制登录页入口，不是后台数据的安全边界；读取后台数据仍必须通过后台账号密码登录并取得后台 Cookie。

## 独立后台登录

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/backoffice/login` | 后台账号登录 |
| `GET` | `/api/backoffice/me` | 获取后台当前用户 |
| `POST` | `/api/backoffice/logout` | 退出后台 |

后台登录请求体：

```json
{
  "account": "admin",
  "password": "deng1201"
}
```

说明：

- 后台账号不复用 AI 助手用户。
- 后台使用独立 HttpOnly Cookie。
- Cookie 名称由 `BACKOFFICE_COOKIE_NAME` 控制，默认 `qx_backoffice_session`。
- 后台账号角色目前有：
  - `admin`：管理员，可查看全部后台内容。
  - `viewer`：观察员，只能查看反馈。

## 独立后台数据

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| `GET` | `/api/backoffice/feedback` | 后台登录用户 | 获取最近反馈 |
| `GET` | `/api/backoffice/logs` | 后台管理员 | 获取最近账号活动日志 |
| `GET` | `/api/backoffice/tool-usage-logs` | 后台管理员 | 分页筛选工具使用日志 |

说明：

- 反馈和账号活动日志接口固定取最近 500 条。
- `viewer` 只能查看反馈；访问账号活动日志或工具使用日志会被拒绝。
- 工具使用日志已经分页，默认每页 30 条，最多每页 100 条，并按 ID 倒序返回。

`GET /api/backoffice/tool-usage-logs` 查询参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `page` | `1` | 页码，最小为 1 |
| `page_size` | `30` | 每页数量，范围 1–100 |
| `start_time` | 空 | 起始时间，ISO 日期时间 |
| `end_time` | 空 | 结束时间，ISO 日期时间 |
| `tool_name` | 空 | 工具名称模糊匹配 |
| `category` | 空 | 分类 slug 精确匹配 |
| `action` | 空 | 操作类型精确匹配 |
| `success` | 空 | `success` 或 `fail` |
| `account` | 空 | 账号模糊匹配 |
| `ip` | 空 | IP 模糊匹配 |

返回的 `data` 为 `{items, page, page_size, total}`。

## Cookie 与权限汇总

| 场景 | Cookie | 说明 |
|---|---|---|
| AI 助手登录 | `SESSION_COOKIE_NAME`，默认 `qx_session` | AI 用户登录态 |
| 独立后台登录 | `BACKOFFICE_COOKIE_NAME`，默认 `qx_backoffice_session` | 后台账号登录态 |

说明：

- 两套 Cookie 独立。
- 后台账号不复用工具站用户。
- 生产 HTTPS 环境建议开启 `SESSION_COOKIE_SECURE=true`。
