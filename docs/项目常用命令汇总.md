# 项目常用命令汇总

本文档汇总 `琦湘工具集合` 日常开发、启动、验证和排查时最常用的命令。

## 项目根目录

```bash
cd /Users/a123/PycharmProjects/qixiang_tools
```

## 后端命令

后端目录：

```bash
cd /Users/a123/PycharmProjects/qixiang_tools/backend
```

安装后端依赖：

```bash
python3 -m pip install -r requirements.txt
```

启动 FastAPI 后端：

```bash
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

使用 `main.py` 启动后端：

```bash
python3 /Users/a123/PycharmProjects/qixiang_tools/backend/app/main.py
```

运行后端测试：

```bash
python3 -m pytest
```

后端健康检查：

```bash
curl http://127.0.0.1:8000/api/health
```

后端接口文档：

```text
http://127.0.0.1:8000/docs
```

## 前端命令

前端目录：

```bash
cd /Users/a123/PycharmProjects/qixiang_tools/frontend
```

安装前端依赖：

```bash
npm install
```

首次配置前端环境文件：

```bash
cp .env.example .env
```

启动 Vite 前端开发服务器：

```bash
npm run dev
```

构建前端生产产物：

```bash
npm run build
```

预览生产构建：

```bash
npm run preview
```

前端访问地址：

```text
http://127.0.0.1:5173/
```

如果 `5173` 被占用，Vite 会自动切到下一个可用端口，比如 `5174`。

## 前后端联调

推荐打开两个终端分别启动：

```bash
cd /Users/a123/PycharmProjects/qixiang_tools/backend
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```bash
cd /Users/a123/PycharmProjects/qixiang_tools/frontend
npm run dev
```

默认前端 API 配置：

```text
VITE_API_BASE_URL=http://127.0.0.1:8000/api
```

如果后端端口或地址变化，修改：

```text
frontend/.env
```

## 常用验证命令

检查后端是否正常：

```bash
curl -sS http://127.0.0.1:8000/api/health
```

检查前端是否返回页面：

```bash
curl -I http://127.0.0.1:5173/
```

检查后端端口是否被占用：

```bash
lsof -nP -iTCP:8000 -sTCP:LISTEN
```

检查前端端口是否被占用：

```bash
lsof -nP -iTCP:5173 -sTCP:LISTEN
```

## 停止服务

在对应的后端或前端终端中按：

```text
Ctrl+C
```
