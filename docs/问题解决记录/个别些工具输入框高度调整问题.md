# 个别些工具输入框高度调整问题

## 背景

小工具页面里的输入框和输出框大多不是每个工具单独写一份，而是复用通用组件和通用样式。

因此改高度时要先确认工具使用的是哪个组件，否则只改 CSS 可能看不到效果。

## 输入框在哪里

常见文本类工具使用：

- 组件：`frontend/src/components/ToolTextForm.vue`
- 样式：`frontend/src/styles/tool.css`

主要结构：

```vue
<textarea v-else v-model="text" :rows="isMediumTextareaTool ? 6 : 14" :placeholder="inputPlaceholder"></textarea>
```

主要样式：

```css
.tool-form textarea {
  min-height: 300px;
}
```

注意：`rows` 会影响 textarea 的实际高度。  
如果只改 `min-height`，但 `rows` 还是很大，比如 `rows="14"`，输入框仍然可能被 14 行撑高。

## 输出框在哪里

文本结果输出使用：

- 组件：`frontend/src/components/ResultPanel.vue`
- 样式：`frontend/src/styles/tool.css`

主要结构：

```vue
<pre v-else-if="typeof result === 'string'">{{ result }}</pre>
```

主要样式：

```css
.result-panel pre {
  max-height: 520px;
  overflow: auto;
}
```

如果要调整输出框高度，一般改 `.result-panel pre` 的 `max-height`。  
如果只想某些工具单独调整，需要给对应工具加 class，再写单独样式。

## 单独调整某些工具输入框高度

如果只想调整个别工具，不要直接改全局的：

```css
.tool-form textarea {
  min-height: 300px;
}
```

否则所有使用 `ToolTextForm` 的工具都会一起变。

推荐做法是在 `ToolTextForm.vue` 里按工具 slug 加 class。

示例：只让以下四个工具的输入框变矮：

- 免费翻译：`free-translate`
- 文本格式清理：`text-format-cleaner`
- 隐形控制字符串打印：`invisible-control-chars`
- 字符统计截取输出：`character-count-slice`

### 1. 修改 `ToolTextForm.vue`

增加工具 slug 集合：

```js
const mediumTextareaToolSlugs = new Set([
  "free-translate",
  "text-format-cleaner",
  "invisible-control-chars",
  "character-count-slice",
]);

const isMediumTextareaTool = computed(() => mediumTextareaToolSlugs.has(props.tool.slug));
```

给表单根节点加 class：

```vue
<section
  class="tool-form"
  :class="{
    'tool-form--compact-input': isCompactInputTool,
    'tool-form--medium-textarea': isMediumTextareaTool,
  }"
>
```

同时调整 textarea 行数：

```vue
<textarea v-else v-model="text" :rows="isMediumTextareaTool ? 6 : 14" :placeholder="inputPlaceholder"></textarea>
```

### 2. 修改 `tool.css`

单独设置这类工具的输入框高度：

```css
.tool-form.tool-form--medium-textarea textarea {
  height: 150px;
  min-height: 150px;
}
```

如果只写：

```css
min-height: 150px;
```

它只是最低高度，实际高度仍可能被 `rows`、行高或浏览器默认样式撑大。  
如果希望高度明确就是 150px，建议同时写 `height` 和 `min-height`。

## 修改后验证

本地开发环境一般会热更新。若页面没变化，先刷新或强刷。

前端构建验证：

```bash
cd frontend
npm run build
```

服务器环境需要重新构建并同步 `frontend/dist`，因为线上读取的是构建后的静态文件。
