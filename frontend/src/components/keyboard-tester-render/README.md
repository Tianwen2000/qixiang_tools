# 键盘测试组件

这一组组件专门服务“键盘测试”工具页。

- `KeyboardVisualizer.vue`：键盘主面板组件，负责整个键盘测试区域的整体布局与状态组织，统一管理功能键区、主键区、编辑区、方向键区和数字小键盘区的渲染，并将按键状态分发到对应的行组件和键帽组件中，是整套键盘测试界面的核心容器。
- `KeyboardStatusBar.vue`：右上角状态栏组件，用于展示键盘测试过程中的辅助信息，例如当前触发的键值或其他状态提示，作为主键盘区域之外的信息补充模块，帮助用户更直观地了解当前测试反馈。
- `KeyboardRow.vue`：键盘行组件，负责按照“行”的维度组织和渲染一组按键数据，统一处理同一行键位之间的排列、间距和对齐关系，使主键区、功能键区、编辑区等多个区域都能够以一致的方式按行展示。
- `KeyboardKeyCap.vue`：单个键帽组件，负责具体按键的外观渲染与状态展示，包括键帽尺寸、单双层字符显示、特殊宽度控制以及不同状态下的样式切换，是整个键盘可视化界面中最基础、最细粒度的显示单元。

## 补充说明
本目录下的 4 个组件主要负责键盘测试界面的展示与渲染，属于视图层组件，不直接承载完整的业务控制逻辑。键盘测试所需的键位布局数据、键盘事件监听、按键状态管理、最后触发键值记录以及音效控制等逻辑，统一由上层的键盘测试控制器器组件`ToolKeyboardTester.vue`负责，并通过 `props` 传入 `KeyboardVisualizer.vue`。因此，这一组组件可以理解为“键盘测试渲染组件”，而完整的“键盘测试控制器`ToolKeyboardTester.vue`”位于外层业务文件中。在完整的“键盘测试控制器`ToolKeyboardTester.vue`中会import KeyboardVisualizer from "./keyboard-tester-render/KeyboardVisualizer.vue";
